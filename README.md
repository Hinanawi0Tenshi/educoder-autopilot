# educoder-autopilot · 头歌作业自动驾驶

给 AI agent 用的**方法论 skill**：把头歌（educoder）实验的关卡一关一关做穿。

> **不附带脚本。** 每门课的表结构、字段、判分点都不同，写死脚本换课就废。
> 这里复用的是"怎么读题、怎么判、怎么改"这套动作，具体实现由 agent 用它自己可用的浏览器控制手段完成。

## 闭环

```
切「学习内容」 → 读文字 + 读配图 → 读编辑器已有框架 → 填答案
      ↑                                                    ↓
      │                                                 点「评测」
      │                                                    ↓
      └── 改 ← 读「测评结果」：左预期输出 vs 右实际输出 ← 未通过
                                                           ↓
                                                    通过 → 下一关 / 完成
```

关键在于第 2 步和第 7 步——这两步决定了你是"三关过一关"还是"一次过"：

- **读题必须看图**。ER 图、表结构图、示例结果截图常常是字段名和数据取值的唯一来源。
- **失败必须读差异**。测评结果左边是预期、右边是实际，差异形态直接指向病因（列名？排序？聚合粒度？），比盲改快一个数量级。

## 安装

```bash
git clone <this-repo> ~/.claude/skills/educoder-autopilot
# 或把目录拷进 ~/.claude/skills/ 或项目的 .claude/skills/
```

不需要 `npm install`，没有可执行文件。

## 怎么用

对 agent 说：

- "用 educoder-autopilot 把这个实验刷完：<任务链接>"
- "把这个头歌任务从当前关卡做到最后一关，已完成的跳过"

agent 会先起一个**带调试端口、用独立 profile 的可见 Chrome**，等你登录完，然后开始循环。
登录永远由你自己完成——它不读密码、不点验证码、不存凭据。

## 文件

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 主循环八步 + 差异对照表 + 纪律与反模式 |
| `references/platform.md` | 头歌页面结构、文案表、Monaco 用法、判题语义（实测值，会随改版失效） |
| `references/pitfalls.md` | 按症状排错，含"平台改版了怎么找回来" |

## 隐私与安全

- **登录态在 Chrome profile 目录里，那等于你的账号。** 不要提交、不要打包外发，仓库自带 `.gitignore`。
- 不要指向你日常使用的 Chrome 用户目录，务必用独立 profile。
- **截图会带真实身份**：判题页右上角通常有姓名、班级、分数，存证截图不要进公开仓库。
- 调试端口默认只监听 `127.0.0.1`；不要加 `--remote-debugging-address=0.0.0.0`。

## 适用范围与限制

- 面向"代码编辑器 + 评测"型关卡。文件上传、选择题、图形化关卡不在此列。
- 文案表与 DOM 结构硬绑头歌当前版本，改版后需按 `references/pitfalls.md` 的 I 节找回来。
- 不做自动化登录，也不应该做。
