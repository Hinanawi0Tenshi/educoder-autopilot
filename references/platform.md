# 头歌（educoder）页面行为实测

> 这些是某一版本下的观察值，**不是契约**。平台改版后文案和结构都会变，
> 变通办法见 `pitfalls.md` 的 G 节。写代码时按文案定位，不要按类名。

## 页面结构

```
https://www.educoder.net/tasks/<courseId>/<taskId>/<levelSlug>
```

- 切关卡时 `courseId` / `taskId` 不变，**只有 `levelSlug` 变** → 判断"是否已进入下一关"看 URL 即可。
- slug 无语义、不可推导，**不能自己拼 URL**，只能点「上一关 / 下一关」。
- 顶栏是标签：`实验助教 / 学习内容 / 参考答案 / 记录 / 评论 / 关卡排行榜`。
  **默认停在「实验助教」**（AI 助手欢迎页），每次导航后都会重置回它。

## 三个区域

| 区域 | 内容 | 怎么读 |
|---|---|---|
| 左栏 | 题目正文、任务描述、**配图** | 切到「学习内容」后取左栏 innerText + 截图 |
| 右上 | Monaco 代码编辑器 | `Monaco.editor.getModels()[0].getValue()` |
| 右下 | 测试结果面板 | 「测试结果」之后的 innerText；或截图 |

## 元素定位（按文案，不按类名）

| 目标 | 文案 |
|---|---|
| 评测（判分） | `评测` |
| 自测运行（不判分，只出查询结果） | `自测运行` |
| 上一关 / 下一关 | `上一关` / `下一关`（底部栏是 `a[href]`，弹窗里的无 href） |
| 最后一关收尾 | `完成` |
| 题目标签 | `学习内容` |
| 未通过的详情 | `测评结果` |

类名形如 `btn-run___fh7pl`、`ghost-link___Y8dGm`、`assistant-tab-spark___xO_lK`，
是构建产物的哈希，**换版本必失效**，只能当调试线索。

## 编辑器

Monaco。改 DOM 的 `textarea` 或 `contenteditable` **无效**，必须走模型 API：

```js
Monaco.editor.getModels()[0].setValue(text)
```

读同理：`Monaco.editor.getModels()[0].getValue()`。

骨架由课程给定，形状通常是：

```
USE <本关的库名>;          ← 逐课不同，可能是 mydata / demo / 自定义
#请在此处添加实现代码
########## Begin ##########
<你的代码>
########## End ##########
```

- 只替换 Begin/End 之间；区间外的库名、注释、签名原样保留。
- 有些关卡骨架是空的（没有 Begin/End）→ 整段自己写，但**库名要照抄同课程其它关卡的首行**，别猜。

## 判题语义

| 面板文案 | 含义 |
|---|---|
| `1/1 全部通过` + 绿色对勾 + `消耗内存 xx MB / 代码执行时长 x.xx 秒` | 通过，同时弹 `+100` |
| `未通过` | 失败，旁边出现「测评结果」可展开 |
| `服务启动中` | 环境冷启动，此时点「评测」会被吞 |
| `0/1 启动环境失败，请稍后重试` | 平台侧故障，与代码无关 |
| 只有 `测试集1` 一行、无对勾无耗时 | 还在跑，再等几秒 |

- 比对的是**结果集**（含列名），不比对代码写法。`> ANY (子查询)` 和派生表 JOIN 只要行集一致都能过。
- 但题面点名"用嵌套查询 / 用连接查询"时按题面写，否则可能被判不符。
- 通过 ≠ 关卡记分。确认标题旁出现 `100` 徽标，或再读一次状态。

## 测评结果面板

未通过时展开，**左边是预期输出，右边是实际输出**（有时预期输出本身就是一张图）。
逐行逐列对比，差异形态对应的病因见 `SKILL.md` 的对照表。
